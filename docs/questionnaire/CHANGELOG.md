# Questionnaire changelog

Every change to `src/survey/questions.ts` that affects what is asked must bump
`SURVEY_VERSION` and be listed here. Never change or remove an existing question or
option ID; a reworded question gets a new ID.

## Version 1 (launch)

- 7 demographic questions, 18 core items (6 dimensions × 3), 1 attention check,
  12 activities, 4 meta questions including the self-assessment.
